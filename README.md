# CodigoAmigo

Plataforma web para compartir códigos de descuento y ofertas.

## Características

- Sistema de gestión de códigos de descuento
- Panel de administración
- Sistema de usuarios
- API REST
- Interfaz responsive
- Integración con múltiples marcas

## Tecnologías

- PHP
- MySQL
- JavaScript
- CSS/HTML
- Bootstrap

## Instalación

1. Clona el repositorio
2. Configura la base de datos en `config/app.php`
3. Instala las dependencias con Composer
4. Configura el servidor web

## Estructura del Proyecto

- `public_html/` - Archivos públicos del sitio web
- `config/` - Archivos de configuración
- `tests/` - Archivos de pruebas
- `documentacion_rediseno/` - Documentación del rediseño
