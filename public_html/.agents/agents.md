# CodigoAmigo Agent Rules

## Cron Jobs / Tareas Programadas

> **IMPORTANTE**: Todos los cron jobs se gestionan mediante **Jenkins**, NUNCA mediante crontab.
> No incluir instrucciones de crontab en los comentarios de los scripts.
> Los headers de los scripts cron deben indicar: `⚠️ Ejecutar via JENKINS (no crontab)`
